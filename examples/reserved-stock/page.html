The question

Only 3 left?

A product page says "Only 3 left". The warehouse shelf holds 10. Is the shop wrong?

How it works, step by step

Shelf minus promised

1. What you already know

In a real shop, an item in another person's basket is still in the shop. But it is not for sale to you. It is promised.

2. What goes wrong online

Online, you cannot see the other baskets. If the shop counted only the shelf, it could sell the same item twice.

3. Two counts

On hand is the number of items on the shelf. Reserved is the number of items promised to orders. The page shows on hand − reserved.

4. Checkout holds

Many shops hold an item while a shopper is in checkout. If the shopper pays, the item stays reserved until it ships. If the shopper leaves, or the time runs out, the item is free again. When a hold starts, and how long it lasts, varies from shop to shop.

5. Two people, the last item

A well-built shop takes one "take one" request at a time. (A shop that does not can sell the same item twice, and must then cancel an order.) The first request finds 1 free item and takes it. The second request finds 0 and stops. That shopper sees "sold out".

  • On the shelf: 10 items.
  • Paid, not yet shipped: 5 items (reserved).
  • Held in a checkout: 2 items (reserved).
  • Reserved in total: 7 items.
  • Free to sell: 10 − 7 = 3. The page shows "Only 3 left".

A common wrong belief

"The item in my cart is mine." In many shops, adding to the cart reserves nothing. The item is yours when the order is confirmed.

Recap

Shown = on hand − reserved. Holds end, so the number can go up again. The last item goes to the first confirmed order.

This describes common practice. Each shop sets its own rules for when items are reserved and for how long.
